# Online Shop Backend

A complete e-commerce REST API built with Spring Boot, MySQL, and JWT authentication.

## 🚀 Tech Stack

- **Java 17**
- **Spring Boot 3.3.5**
- **Spring Security + JWT**
- **Spring Data JPA / Hibernate**
- **MySQL 8**
- **Lombok**
- **Maven**

## ✨ Features

- 🔐 JWT Authentication (register, login)
- 👥 Role-based access (ADMIN, SELLER, BUYER)
- 📂 Category management
- 📦 Product management (with multi-image upload)
- 🛒 Shopping cart
- 📋 Order management
- 💳 Payment (mobile money - M-Pesa, Tigo, Airtel, Halotel)
- 📊 Admin dashboard
- 📤 File upload
